# ModelingToolkit

Declare variables and parameters, define the differential and equations, build and simplify an ODESystem, then create an ODEProblem, solve it, and plot the named states.

Open these files with Pluto; their first cell activates and installs the shared
repository environment automatically. See the [course index](../../../README.md)
for the matching topics in the other tracks.

Use `sol[x]` to select a symbolic state, even if MTK reorders the internal state vector.
The code follows the [MTK 9 ODE workflow](https://docs.sciml.ai/ModelingToolkit/v9.41/tutorials/ode_modeling/).
